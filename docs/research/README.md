# M0 research materials

Scripts and note templates for the Phase 1 (M0 Validate) interviews in `ROADMAP.md`: `M0-01` (senders), `M0-02` (payees), `M0-03` (attesters). These feed the go/pivot/stop decision (`M0-11`, `DEC-17`) against `PRD.md` §8.2 (pivot triggers) and §10 (assumptions to validate).

## Before you start

- **This repo is public.** Do not commit real names, contact details, institution-identifying specifics, or anything else that could identify an interviewee. Log answers against an interview ID (e.g. `S-01`, `P-01`, `A-01`), role, country, and the substantive answer only.
- If a note would be identifying no matter how it's phrased, keep it out of this repo (local file, shared privately with the team) and record only the theme it contributes to in the log tables below.
- Each guide below ends with a log table. Append one row per completed interview in a follow-up PR; don't edit past rows.

## Files

| File | Roadmap row | Target |
|---|---|---|
| `m0-01-sender-interviews.md` | `M0-01` | 15 senders, ≥ 2 candidate markets |
| `m0-02-payee-interviews.md` | `M0-02` | 5 payees (schools/landlords), incl. wallet willingness |
| `m0-03-attester-conversations.md` | `M0-03` | ≥ 2 attesters (associations, NGOs) |

## After interviews are logged

Summarize themes at the bottom of each file once its target count is reached, then roll the synthesis into `M0-11`'s findings report. Don't mark a row `DONE` in `ROADMAP.md` until its "Done when" criteria are actually met with real data — a drafted script/template is `IN PROGRESS`, not `DONE`.
